# Joohye Jeong — Academic Website

Personal academic website for Joohye Jeong, Ph.D. candidate in Political Science and Statistics at MIT.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload this folder.
2. Use `main` as the default branch.
3. In the repository, open **Settings → Pages** and select **GitHub Actions** under **Build and deployment**.
4. The included workflow will build and publish the site after every push to `main`.

The site supports both a personal `username.github.io` repository and a regular project repository.
